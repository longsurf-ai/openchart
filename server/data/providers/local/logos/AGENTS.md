# Bundled logos

Owns `openchart.logos`, its packaged assets and alias catalog.

- `assets/catalog.json` owns identities, explicit aliases and verified listing
  evidence. Every entry requires a symbol, venue and source URL. Parse once;
  IDs are unique ignoring case and image paths stay inside the bundle.
- Canonical IDs cannot be shadowed. Exact aliases win; pair aliases are data,
  not generated by the runtime. `stock:`/`crypto:` and exchange-qualified aliases
  disambiguate ticker collisions. Ambiguous bare identifiers remain ambiguous.
  Fuzzy name matches require five characters and allow a prefix or one edit.
- Retain only verified publicly traded issuers or traded crypto, not arbitrary
  brands, subsidiaries, institutions or obsolete tokens. See `AUDIT.md` for
  sources and coverage; same-ticker names alone cannot establish identity.
- Read image bytes only for requested candidates. Read/parse failures are
  `Dataset.InvalidResult`; Feed dies on them (a packaging defect), never `null`.
- Desktop copies `assets/` beside the compiled backend. No source-checkout paths,
  remote requests, credentials, or frontend asset lookup are required.
