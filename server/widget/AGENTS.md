# widget

Owns custom widget runtime support; the Resource lives in
`resources/custom-widget`. See
[custom widgets](../../docs/architecture/custom-widget.md).

- `compile.ts` checks a source snapshot with strict TypeScript against the
  bundled SDK declarations (`.artifacts/widget-types`, generated by
  `app/tooling/widget-types.ts`) and reads `kind`/`title` statically. Imports
  come from `modules.json`; dynamic imports, `require`, references and
  `@ts-` suppression comments fail.
  Workspace config and packages never take part. `transpileWidget` serves
  saved snapshots without type checking.
- The example the Agent copies is `docs/agent/price-chart.widget.tsx`, shipped
  beside its guide; the Resource and `save_widget` tests save it.
- `errors.ts` owns `WidgetInvalid`, public as `widget.invalid`.
