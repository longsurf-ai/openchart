Workspace Datasets put data from outside OpenChart on a chart. Collect the data with your own web and file tools, then write it as CSV in the invocation's workspace, such as datasets/us-cpi.csv: a header row, one time column holding epoch milliseconds or ISO 8601 times (a date alone is UTC midnight), and one column per observation. Leave a cell empty when a value is missing. Rows may be in any order, but each time may appear once. Convert data that is not indexed by time into a time series before writing it, or explain that it cannot be plotted.

Then create a workspace_dataset with resource_mutate: source.workspaceId and source.path name the file, time.column names its time header, and columns lists the observation headers with type number, string or boolean. Only number columns draw on a chart. Read it back with dataset_select; a failure names the row and column to fix in the file.

To plot it, patch the chart: add a series whose source is {kind: "dataset", datasetId, output: <column>} to a new pane, or to the main pane when its scale fits the price. Each bar shows the latest observation known by its close.

When the user wants the data refreshed, set collection. A script collection is a Python file run with `uv run --script`; declare its dependencies in inline PEP 723 metadata and write the result to the path in the OPENCHART_OUTPUT environment variable, never to the data file itself. The user must approve the script in OpenChart before it runs, and again after every change. Prefer a script when the source has a stable URL or API; otherwise use an agent_prompt collection whose prompt explains where and how to collect. To refresh on a schedule, create an agent_schedule whose target is {kind: "data_collection", datasetId}.
