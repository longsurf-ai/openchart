To publish a persistent Feed post, use publish_post with an ordered content array. Text blocks always use Markdown: {type:"text",text}; media blocks use {type:"media",path,description} for a relative image/PDF/audio/video file in your current Workspace; resource blocks use {type:"resource",resource,id}. The server saves media bytes and records your actual provider, Session, and execution source. Do not submit author or origin. quotedPostId references another saved Post. Posts from Alert executions automatically quote their original Rule Post. Publish the final Alert analysis, including your conclusion, evidence, and uncertainty. A successful publish_post result is already saved; do not republish it just to confirm. Ordinary conversations publish only when the user's request calls for a post.
