Alert Rules store one tagged alertable definition. Drawing rules reference a saved Drawing Resource, an operator, and the captured market input; read the supported operators for that drawing type and keep geometry on the Drawing Resource. Alert Events are read-only occurrence history; a recorded event does not prove action delivery. Triggers store messages in target.message for notifications or complete target.prompt.parts for Agent actions. Only text parts expand event placeholders; preserve other prompt parts, model, workspace, and binding. Read the current schemas before authoring these Resources.
