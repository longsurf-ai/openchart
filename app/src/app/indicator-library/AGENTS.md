# Study library composition

- App composes Chart discovery and Session navigation.
- assistant-ui owns the search draft. Only Enter/Send creates a Session.
  Create/modify actions prefill; Copy only copies.
  Close and navigate before submitting the unchanged draft; the full-page host
  owns execution, follow-ups and retries.
- Capture chart/cell/source before creation; Agent owns execution, transcript,
  model/workspace, permissions and failures.
- Use normal Dialog lifecycle. The standalone composer retains unsent drafts
  until Session creation.
- Previews share packaged real historical examples; Query caches each asset.
  Balance the full catalog across a stable shuffled pool, never filters.
  Curated windows bound price and execution together; later signals stay absent.
  Card/detail agree. Provenance stays in assets; no captions or example picker.
  Finite supplied inputs never acquire Feed data, including secondary requests.
  Pan/zoom never expands execution bounds. Mount the entire active tab once;
  scrolling only suspends painting, never releases a study's execution or data.
- Discovery ranks 30 curated studies under semantic goals; All retains originals.
  Use a horizontal featured study and responsive three-column gallery.
  Details pair a guide with nonempty Inputs, then a prompt; Open source precedes Add.
- Use shared Dialog sizing and viewport limits, stable across views.
  No logo or Settings.
