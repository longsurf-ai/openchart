# Pine conversion film

`pine-conversion.mp4` follows the approved fifteen-frame storyboard. It is a
15-second, 1536 × 1024, 60 fps, silent H.264 film with faststart metadata.
One independent cursor follows continuous eased paths through code selection,
Copy, the composer, Send, the generated file, the Dashboard, and Add to chart.
Selection grows with the drag; the composer expands on paste, the submitted
message moves into the transcript, and the reply appears line by line. Clicks
drive the file and chart updates. The final cursor and picture return to the
opening state for looping. The landscape UI retains its 3:2 geometry and native
pixel sizes. `poster.png` is the opening frame; `pine-conversion.vtt` supplies
optional English captions. A matching 24 fps GIF is exported for sharing.

The frames were generated from screenshots of the running desktop application
and reviewed before rendering. They show a TradingView mock, copying Pine source,
pasting and sending in the OpenChart sidebar, an agent response, the generated
Tea file, and Add to chart on NVDA. The completed result stays visible before the
loop returns to the start. This is an illustrative demonstration, not evidence
of native TradingView rendering parity. Waiting time is condensed.

The Trellis PageView uses the shared Dialog with native pause and fullscreen
controls. Reduced motion leaves playback manual. The workflow is offered once
per device, shared between an explicit Indicators open and a newly saved
Workspace widget on the current Dashboard. Opening the Workspace page, loading
an existing placement, and changing dashboards do not offer it. It waits for an
existing tour on the same page and expires if that page is left.

The accompanying Pine and Tea examples define five inputs, seven plot columns,
four translucent fills, and two confirmed trend annotations. The Tea version was
compiled and attached to an NVDA chart during reference capture. Validation on
502 packaged historical NVDA bars compared 3,462 finite values to independent
EMA/Wilder ATR formulas and checked 14 crossovers, warmup missingness, colors,
fill links, and annotation text. Watching the film creates no product resources.
